# Registro de Prompts de Inteligencia Artificial (IA)

Este archivo documenta el uso de un asistente de IA durante el desarrollo de este taller, en cumplimiento con las instrucciones del proyecto.

Se utilizó apoyo de IA como herramienta de consulta y generación de código durante la implementación del patrón CQRS sobre el proyecto Shortly, incluyendo la separación de modelos de Command y Query, los handlers correspondientes, los repositorios de lectura/escritura, el modelo de lectura optimizado (`LinkReadModel`) y su sincronización, y el refactor de los endpoints para eliminar la dependencia del servicio original.

Todo el código generado con apoyo de IA fue revisado, ajustado y validado por el equipo antes de integrarlo al proyecto.
